# Помощник Мастера игры для настольных ролевых игр по редакции D&D 5e

## Описание проекта

Программа предназначена для Ведущих (Мастеров Игры) настольных ролевых игр (на базе правил D&D 5e) для автоматизации рутинных математических расчетов во время подготовки и проведения игровых сессий. Она решает задачу быстрой генерации сбалансированных боевых столкновений, отслеживания инициативы и статусов персонажей в реальном времени, а также автоматического распределения добычи, позволяя Мастеру сфокусироваться на сюжете и отыгрыше, а не на отслеживании состояния битвы, проходящей по правилам игры.

## Ключевые функции

1. **Генератор столкновений:** Мастер задает желаемую сложность (от легкой до смертельной), а программа автоматически подбирает группу монстров из базы, рассчитывая их суммарный рейтинг опасности (CR) и корректируя XP по правилам *Dungeon Master's Guide*.

2. **Трекер инициативы:** Выстраивает очередь ходов игроков и монстров, позволяет в реальном времени изменять HP, применять каноничные статусы (отравлен, испуган и т.д.) и автоматически удаляет погибших существ из боя.

3. **Распределитель добычи:** По завершении боя рассчитывает денежную награду и генерирует магические предметы в зависимости от сложности побежденных врагов.

## Процесс работы с программой

Мастер Игры запускает сессию и вводит данные персонажей игроков, либо загружает их из файла. При подготовке к битве он задает желаемую сложность (например, смертельная), а программа автоматически подбирает группу монстров из базы, рассчитывая их суммарный рейтинг опасности. Когда начинается бой, Мастер переводит сгенерированную группу в трекер инициативы. Система запрашивает броски инициативы для игроков, автоматически бросает кубики за монстров, выстраивает очередь ходов и позволяет Мастеру изменять здоровье участников, применять состояния и удалять убитых врагов из очереди. По завершении боя модуль генератор добычи рассчитывает награду (золото и предметы) в зависимости от сложности побежденных врагов.
